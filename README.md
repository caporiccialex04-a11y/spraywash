# Spray Wash Car Wash

Marketing website for Spray Wash Car Wash (Grand Rapids, MI) — five self-serve bays and one automatic wash. Powered by Under-Pressure.

## Stack

- Vite
- Vanilla HTML / CSS / JS

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Brand colors follow the Spray Wash logo: orange `#E87722`, black, and white.
- Layout pacing is inspired by [Deluxe Communities](https://deluxecommunities.com/) (sticky header, full-bleed rotating hero, pathway boxes, split content sections).
- Service copy adapted from the Clear Choice Car Wash draft and rewritten for Spray Wash branding.
